CivicSense

Agentic AI-Powered Intelligent Civic Grievance Detection, Prioritisation and Resolution Platform

CivicSense is an AI-powered civic issue management platform designed to detect, analyse, prioritise, and track urban infrastructure complaints.

Key Features

* AI-based civic issue detection using YOLO
* Intelligent complaint classification
* Duplicate complaint detection
* Geospatial complaint analysis
* Severity-based prioritisation
* Automated department recommendations
* Multi-agent complaint monitoring
* AI-assisted resolution verification
* Civic analytics dashboard

Technology Stack

* Frontend: React, TypeScript
* Backend: Python, FastAPI
* Database: PostgreSQL, PostGIS
* AI/ML: YOLO, OpenCV, Scikit-learn
* Agentic AI: LangGraph, MCP
* Background Processing: Celery, RabbitMQ
* Caching: Redis
* Infrastructure: Docker
